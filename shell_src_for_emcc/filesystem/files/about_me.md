## :computer: What is SpicyOS?

**SpicyOS** is a fake desktop environment I built as my portfolio because standard portfolio sites were putting me to sleep.

Under the dramatic little cyberpunk shell, it includes:

- A working **terminal** inspired by POSIX shells
- A **file system** and window manager built in Vue
- Backend logic compiled from **C++ to WebAssembly** via Emscripten
- A **Sanity-backed content model** for the portfolio filesystem
- Custom interaction, state, animation, and navigation behavior

The project is deliberately excessive, but the thinking behind it is practical: structure information clearly, connect different technical layers, and make a complicated system understandable to the person using it.
